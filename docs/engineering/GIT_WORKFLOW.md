# Git Workflow

Git is taught gradually. Do not force complicated Git Flow early.

## Start with

`git init`, `git status`, `git add`, `git commit`, `git diff`, `git log`, branches.

## Later

Pull Requests, code review, conventional commits, feature branches, CI/CD.

## Rules

- Each meaningful implementation milestone produces a meaningful commit.
- Commit quality is taught gradually.

## Commit message convention

UNDECIDED. Decide when conventional commits are introduced.
